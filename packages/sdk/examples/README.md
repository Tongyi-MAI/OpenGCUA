# SDK examples

Runnable examples live in `src/`:

- `unified_macos.py` observes a running TextEdit instance through the macOS adapter.
- `browser.py` and `browser.mjs` exercise the Playwright provider.
- `linux.py` and `linux.mjs` observe an existing Ubuntu X11 desktop.
- `unified_android.py` observes an explicitly selected Android device.
- `macos_cells.py` and `repl_cells.py` are cells for the optional persistent REPL.

Install the SDK and any adapter-specific dependencies first; see the
[SDK guide](../README.md) and [Quick Start](../../../QUICKSTART.md).
